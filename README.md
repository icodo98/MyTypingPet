# 타이핑 펫 (MyTypingPet)

키보드를 칠 때마다 화면 구석에서 움직이는 데스크톱 펫입니다.
**그림(PNG)만 바꿔 넣고 `build.bat`을 더블클릭하면** 나만의 캐릭터로 바뀝니다.
Windows에 기본으로 들어 있는 C# 컴파일러를 쓰기 때문에 따로 설치할 것이 없습니다.

## 빠른 시작

1. `build.bat` 더블클릭 → 같은 폴더에 `MyTypingPet.exe`가 생깁니다.
2. `MyTypingPet.exe` 실행 → 오른쪽 아래에 임시 캐릭터(민트색 동글이)가 나타납니다.
3. 아무 창에서나 타이핑해 보세요.

## 내 캐릭터로 바꾸기

`sprites` 폴더 안의 동작별 폴더에 그림을 넣습니다. 폴더 안의 PNG는 **파일 이름 순서대로** 재생됩니다.

| 폴더 | 언제 | 재생 방식 | 임시 그림 |
|---|---|---|---|
| `idle`  | 가만히 있을 때 | 반복 | 숨쉬기 + 눈 깜빡 (6장) |
| `type`  | 보통 속도로 칠 때 | 반복 | 키보드 두드리기 (4장) |
| `fast`  | 아주 빠르게 칠 때 | 반복 | > < 표정으로 다다다 (4장) |
| `back`  | 백스페이스 | 한 번 | 뒤돌아 한 바퀴 (6장) |
| `enter` | 엔터 | 한 번 | 만세 점프 (6장) |
| `rest`  | 한동안 안 칠 때 | 한 번 (마지막 장에서 멈춤) | 옆으로 눕기 (5장) |
| `sleep` | rest 다 끝난 뒤 | 반복 | z z z (3장) |

- **그림 규칙**
  - 배경이 **투명한 PNG**로 그리세요.
  - 캐릭터 **발이 그림 아래쪽 가운데**에 오도록 맞추세요. 그림마다 크기가 달라도 이 기준점으로 맞춰서 그립니다.
  - 모든 동작을 **같은 캔버스 크기**로 그리면 가장 깔끔합니다. 임시 그림은 160×160입니다.
- **파일 이름**: 영문·숫자만 쓰세요. 예: `00.png`, `01.png`, `02.png` …
- **폴더를 비워 두면** 다른 동작 그림을 대신 씁니다.
  - `fast`, `back`, `enter`가 비어 있으면 `type`을 씁니다.
  - `rest`가 비어 있으면 `idle`을 씁니다.
  - `sleep`이 비어 있으면 `rest`의 마지막 장을 씁니다.
  - 최소한 `idle`이나 `type` 중 하나에는 그림이 있어야 합니다.
- **exe 아이콘**: `app.ico`를 바꾸면 됩니다. 이 파일을 지우면 기본 아이콘이 쓰입니다.
  - PNG를 ICO로 바꿔 주는 무료 사이트를 쓰면 됩니다.
  - 트레이 아이콘은 `idle` 첫 장에서 자동으로 만들어집니다.

그림을 바꾼 뒤에는 **켜져 있는 펫을 종료하고** `build.bat`을 다시 실행하세요.

## 이름·속도 같은 설정 바꾸기

[src/Config.cs](src/Config.cs) 한 파일에 모아 두었습니다.

- `AppName`: 메뉴와 트레이에 보이는 이름
- `AppId`: 설정 저장과 중복 실행 방지에 쓰는 ID
  - 영문만 쓰세요.
  - 여러 펫을 같이 켜려면 펫마다 다르게 지어 주세요.
- `AboutText`: "정보" 메뉴의 글 (만든 사람 이름 등)
- `FastKeysPerSecond`: 1초에 몇 번 이상 치면 `fast` 동작이 나올지
- `Fps(...)`: 동작별 애니메이션 속도
- `BounceOnType`, `HopOnWakeUp`: 키를 칠 때 몸이 눌리는 정도와, 쉬다가 깰 때 뛰어오르는 높이
- 크기·쉬는 타이밍 메뉴의 선택지

exe 파일 이름은 `build.bat` 맨 위의 `set NAME=MyTypingPet`에서 바꿉니다.

## 사용법

- **끌어서 이동**: 펫을 마우스로 끌면 옮겨집니다. 위치는 기억됩니다.
- **우클릭 메뉴**: 펫이나 트레이 아이콘(작업표시줄 오른쪽 아래 `^` 안)을 우클릭하면 다음 메뉴가 나옵니다.
  - 크기, 쉬는 타이밍, 항상 위에 표시, 위치 고정, Windows 시작 시 자동 실행, 불러오기, 종료
- **다시 불러오기**: exe를 한 번 더 실행하면, 이미 켜져 있는 펫이 오른쪽 아래로 돌아옵니다.

## 구조

```
src/
  Program.cs    시작점. 중복 실행 막기 + 이미 켜져 있으면 "돌아와" 신호 보내기
  PetForm.cs    펫 창. 동작 상태 결정, 애니메이션, 투명 창 그리기, 메뉴
  KeyHook.cs    전역 키보드 훅. 키 번호만 넘기고 글자는 해석·저장하지 않음
  SpriteSet.cs  exe에 들어 있는 PNG를 동작별로 읽기
  Settings.cs   설정 저장(HKCU\Software\<AppId>), 자동 실행 등록
  Native.cs     Windows API 선언
  Config.cs     바꿔도 되는 값 모음
sprites/        동작별 그림 (빌드할 때 exe 안에 들어감)
build.bat       빌드
```

## 알아 두면 좋은 점

- **백신 경고**: 전역 키보드 훅을 쓰기 때문에, 서명 없는 exe는 백신(V3, Windows 보안 등)이 의심할 수 있습니다. 필요하면 예외로 허용하세요.
- **관리자 권한 창**: 관리자 권한으로 실행된 창에서 칠 때는 Windows 보안 정책 때문에 반응하지 않습니다.
- **설정 초기화**: 레지스트리 `HKCU\Software\MyTypingPet` 키를 지우면 됩니다.
- **완전히 지우기**: 자동 실행을 켰다면 먼저 끄고, 펫을 종료한 뒤 폴더를 지우면 됩니다.
- **캐릭터 저작권**: 다른 작품의 캐릭터를 쓰면 혼자 쓰는 정도는 몰라도, 배포할 때는 문제가 될 수 있습니다. 직접 만든 캐릭터를 쓰세요.
