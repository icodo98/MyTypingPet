타이핑 펫 (MyTypingPet) 사용 설명서
====================================

타이핑 펫은 키보드를 누를 때마다 화면 한쪽에서 움직이는 Windows 데스크톱 친구예요.

1. 처음 실행하기
----------------

1) GitHub의 MyTypingPet 저장소에서 「Code」 → 「Download ZIP」을 누르세요.
2) 받은 ZIP 파일을 우클릭하고 「모두 압축 풀기」를 선택하세요.
3) 압축을 푼 폴더의 「build.bat」을 더블클릭하세요. Windows가 내 PC에서
   실행 파일을 만들어요. 「Build OK: MyTypingPet.exe」가 나오면 완료예요.
4) 같은 폴더에 생긴 「MyTypingPet.exe」를 더블클릭하세요. 화면 오른쪽 아래에
   펫이 나타나면 메모장 같은 창에서 타이핑해 보세요.

파일 확장자가 숨겨져 있으면 「build」와 「MyTypingPet」으로 보일 수 있어요.
직접 빌드해도 Windows 보안 정책에 따라 차단될 수 있어요. 회사나 학교 PC에서
빌드나 실행이 차단되면 IT 관리자에게 문의하세요.

2. 타이핑하고 펫 옮기기
----------------------

- 타이핑하면 펫이 움직이고, 빠르게 치면 다른 동작을 보여 줘요.
- 백스페이스와 엔터를 누르면 각각의 특별한 동작을 볼 수 있어요.
- 타이핑을 멈추면 잠시 뒤 누워서 쉬다가 잠들어요. 다시 치면 깨어나요.
- 펫을 마우스로 끌어서 원하는 곳에 놓으세요. 다음에 켜도 위치를 기억해요.

3. 설정 바꾸기
--------------

펫을 우클릭하거나 작업 표시줄 오른쪽 아래의 펫 아이콘을 우클릭하세요.
아이콘이 안 보이면 「^」(숨겨진 아이콘)를 눌러 찾아보세요.

- 「크기」에서 펫의 크기를 바꿀 수 있어요.
- 「쉬는 타이밍」에서 타이핑을 멈춘 뒤 얼마나 지나면 쉴지 고를 수 있어요.
- 「항상 위에 표시」를 켜면 다른 창 위에 펫이 보여요.
- 「위치 고정 (마우스로 안 움직임)」을 켜면 끌어도 움직이지 않아요.
- 「Windows 시작 시 자동 실행」을 켜면 Windows에 로그인할 때 펫도 켜져요.

4. 펫이 안 보이거나 움직이지 않을 때
------------------------------------

- 작업 표시줄 오른쪽 아래의 펫 아이콘을 더블클릭하거나 우클릭해서
  「오른쪽 아래로 불러오기」를 선택하세요. 「MyTypingPet.exe」를 다시 열어도 돼요.
- 펫은 보이는데 특정 창에서만 움직이지 않으면 메모장에서 타이핑해 보세요.
  관리자 권한으로 실행한 창에서는 펫이 키 입력에 반응하지 않을 수 있어요.

5. 개인정보
-----------

펫은 애니메이션을 고르는 데 키가 눌린 시점과 키 종류를 사용해요.
입력한 글자를 읽거나 저장하거나 전송하지 않아요.

6. 종료하고 지우기
------------------

펫이나 펫 아이콘을 우클릭한 뒤 「종료」를 누르세요.
더 이상 쓰지 않으려면 「Windows 시작 시 자동 실행」을 먼저 끄고, 펫을 종료한 뒤
압축을 풀었던 폴더를 지우면 돼요.
